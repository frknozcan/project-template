# Decision record template

> **Purpose:** the skeleton of one decision record. Copy everything below the rule to `docs/decisions/YYYY-MM-DD-<slug>.md` and replace every placeholder block.
> **Reader:** agent, when the owner has decided something.
> **Authority:** `docs/decisions/README.md` owns the rules; this file only gives the shape.
> **Updated when:** the record shape changes.
> **Status:** CURRENT. The placeholder blocks in this file stay: it is a template, not a record.
